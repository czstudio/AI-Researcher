# Literature Review 方法论

1. 检索：mcp__paper_search__unified_paper_search 覆盖主线索 + mcp__paper_search__search_papers_by_source 补充单一来源；近 N 年窗口按用户要求。
2. 证据抽取：逐篇记录 claim/evidence/数字结果到 data/evidence_extraction.md，禁止编造。
3. 结构：Title/Abstract/Introduction/Related Work/Taxonomy/Discussion/Conclusion/References。
4. LaTeX 交付时图表优先规划；引用一律入 references.bib（arXiv id / DOI 可解析）。
5. 综合而非罗列：按方法族群聚类对比，指出 knowledge gap。
